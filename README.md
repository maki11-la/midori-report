# ミドリ 投資レポート・ビューア

ミドリの日次・週次の投資戦略レポートを、ブラウザで見やすくまとめたビューアです。

公開ページ: https://maki11-la.github.io/midori-report/

ネットなしでも使えます。`index.html` をダブルクリックして開くか、公開ページを一度開いたあと（スマホならホーム画面に追加）、オフラインでも閲覧できます。

## 見る

- 左の一覧から日付を選ぶ
- 検索ボックスで全文検索
- `j` / `k` または矢印キーで前後のレポートへ
- 「年表」で結論の流れを横断表示
- 配色ボタンでライト／ダーク切替（初回は端末の設定に従います）
- 最後に開いたレポートは端末に記憶されます

iPhone の Safari では、共有ボタンから「ホーム画面に追加」すると、アプリのように開けます。初回に一度オンラインで開けば、その後はオフラインでも使えます。

数字の色は日本株の慣例です。上昇は赤、下落は緑。円安・円高は別色です。

## レポートを足す（公開ページの自動更新）

1. `reports.json` の配列に、次の形のオブジェクトを追加する。

```json
{
  "date": "2026-11-22",
  "title": "夜の戦略レポート 11/22(日)、前日からの変化点",
  "type": "日次",
  "conclusion": "一行の結論。",
  "conclusion_full": "結論の全文（Markdown可）",
  "markdown": "レポート本文（Markdown。文言や数字は変えない）\n"
}
```

`type` は `日次` または `週まとめ`。

- `conclusion_full` は、本文中の `**結論:**` に続く結論の全文。省略すると `conclusion` を使う。
- `conclusion` はサイドバーと年表用の短い一行。通常は結論の先頭1文。1文だけだと短すぎるときは2文まで。

2. トークンを入れた状態で次を実行する。`index.html` とサービスワーカーを再生成し、変化があればコミットして GitHub Pages にプッシュする。

```bash
MIDORI_GH_TOKEN=... ./update.sh
```

ローカルで見るだけなら `python3 build.py` でもよい。


## 見た目を直すとき

- 画面(HTML/CSS/JS)は `template.html`、数字カード・今日の一言・短い結論の取り出しは `summary.py` にあります。
- `build.py` が `reports.json` と上の2つから `index.html` と `sw.js` を作ります。`reports.json` は変えません。
- 数字カードは本文にそのまま書かれた数字だけを拾います(見つからない指標は出しません)。

## 新しい形式のレポート (2026-11-23〜)

ミドリのレポートが「今日の要点 / 5資産の現在地 / 材料の読み方 / 注目する価格の節目 / 次の予定 / カレンダーの変更」(土曜は週間の値動き・資金の流れ・来週のシナリオ・30日以内の重要日程つき)に変わりました。

- `v2.py` が見出しの表記ゆれ(`##` / `**太字**` / 番号つき / 「:」つき)を許して読み取り、`template.html` が専用の表示(要点3行・5資産カード・強気/弱気の並列カード・価格の節目ラダー・予定チップ・シナリオカード)にします。
- 読み取れなかった部分は捨てずに、本文のまま折りたたみで出します。数字は本文にあるものだけを使い、無い資産は「不明」と表示します。
- 旧形式(「結論」あり)の22件は今まで通りの表示です。形式はレポートごとに自動で判定します。
- `reports.json` に足すのは `date` と `markdown` だけで足ります。`title`・`type`・`conclusion` は無ければ自動で補います。
- 確認: `python3 build.py` の最後に `Latest YYYY-MM-DD: format=v2 sections=...` と、読み取れなかった点の `WARN ...` が出ます。
- 見た目の確認用: `python3 build.py --preview fixtures/reports-test.json` で `preview.html` を作ります(`fixtures/` と `preview.html` はコミットしません)。
